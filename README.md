# SportSpace 

Sistema web para la búsqueda, reserva y administración de canchas deportivas.

## Descripción

SportSpace es una aplicación web desarrollada como proyecto académico que permite conectar a clientes que desean reservar canchas deportivas con propietarios que administran sus establecimientos desde una misma plataforma.

El sistema facilita la gestión de reservas, horarios, usuarios y canchas mediante una interfaz intuitiva y un panel de administración para cada tipo de usuario.

---
# Características principales

### Para clientes

* Registro e inicio de sesión.
* Búsqueda de canchas deportivas.
* Visualización de información de cada cancha.
* Consulta de disponibilidad por fecha y horario.
* Reserva de canchas.
* Historial de reservas.
* Edición del perfil.

### Para propietarios

* Registro como propietario.
* Administración de canchas.
* Creación, edición y eliminación de canchas.
* Configuración de horarios disponibles.
* Gestión de reservas.
* Administración de imágenes de las canchas.
* Visualización de estadísticas básicas.

### Para admin

* Gestión de usuarios.
* Gestión de propietarios.
* Gestión de clientes.
* Gestión de canchas.
* Supervisión de reservas.
* Administración general del sistema.

---

# Arquitectura

El sistema utiliza una arquitectura cliente-servidor.

* Frontend encargado de la interfaz de usuario.
* Backend desarrollado con Spring Boot.
* Base de datos MySQL para almacenar la información.
* Cloudinary para el almacenamiento de imágenes.

---

# Flujo general del sistema

1. El usuario crea una cuenta.
2. Inicia sesión.
3. Selecciona una cancha.
4. Consulta los horarios disponibles.
5. Realiza una reserva.
6. El propietario administra la reserva desde su panel.
7. El administrador supervisa el funcionamiento general del sistema.

---

# Roles del sistema

## Cliente

Persona que realiza reservas de canchas deportivas.

## Propietario

Usuario encargado de administrar uno o más canchas deportivas y gestionar las reservas recibidas.

## Administrador

Responsable del mantenimiento y supervisión general de la plataforma.
